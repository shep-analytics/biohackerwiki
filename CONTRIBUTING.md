# Contributing to Biohacking Wiki

Thank you for helping build this community resource! This guide covers how to contribute effectively.

---

## Getting Started

1. **Create an account** on the wiki (sign in with Google)
2. **Read the [Governance](./GOVERNANCE.md)** to understand our standards
3. **Start small** — Fix typos, add references, improve clarity
4. **Build trust** — Quality contributions unlock full publishing rights

---

## How to Contribute

### Creating New Articles
1. Check if the topic already exists (search first!)
2. Use the [article template](./templates/article-template.md)
3. Save as draft for review
4. An editor will review and publish or provide feedback

### Editing Existing Articles
1. Make your changes
2. Write a brief summary of what you changed
3. Minor edits (typos, formatting) go live immediately for editors
4. Substantive changes may require review

---

## Style Guidelines

### Writing
- **Be concise** — Respect readers' time
- **Use plain language** — Avoid jargon when possible
- **Lead with the important stuff** — Summary first, details after
- **Stay neutral** — Present facts, not opinions

### Formatting
- Use headers to organize content (`##`, `###`)
- Use tables for comparisons and dosing info
- Use bullet points for lists
- Bold key terms on first use

### Citations
- Link to original sources when possible
- Prefer: peer-reviewed studies > reputable sites > user reports
- Use inline links: `[study](https://...)`

---

## What Makes a Great Article

✅ Clear, scannable structure  
✅ Evidence labels (🟢🟡🔴)  
✅ Safety information included  
✅ Multiple sources cited  
✅ Neutral, informative tone  

❌ Promotional language  
❌ Unsourced claims  
❌ Missing safety info  
❌ Walls of text
