# Biohacking Wiki

An open-source, community-driven knowledge base for biohacking, nootropics, supplements, and self-optimization.

## 🌐 Live Wiki

Coming soon — hosted on [Outline](https://www.getoutline.com/)

## 🎯 Mission

Create a comprehensive, evidence-based resource for biohackers that:
- Fills gaps left by limited resources like examine.com
- Covers more than just psychoactives (unlike psychonautwiki)
- Is community-editable with quality controls

## 🚀 Deployment

This wiki is deployed using:
- **Platform**: [Outline](https://www.getoutline.com/) (Notion-like editor)
- **Hosting**: [Railway](https://railway.app/) (one-click deploy)
- **Database**: PostgreSQL (managed by Railway)

### Quick Deploy
1. Go to [Railway's Outline Template](https://railway.app/template/PFKwlY)
2. Click "Deploy Now"
3. Configure authentication (Google OAuth recommended)
4. Start writing!
